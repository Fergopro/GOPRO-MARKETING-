# GoProcures motion upgrade — 19 October 2026

The existing homepage and Voice AI page now use two selected GetLayers recipes:

- Orb Studio **Violet Nebula**, using its recommended MIT-licensed `orbloom@0.1.0` package, bundled locally. The palette is adapted to GoProcures blue and purple.
- Liquid Colour **Violet Crown / Aurora**, using its exported shader mathematics with a darker GoProcures palette and a bounded render budget.

Source tools: https://www.getlayers.ai/tools/orb-studio and https://www.getlayers.ai/tools/liquid-colour

`assets/atmosphere.js` wraps the visual runtime. The existing voice engine emits numeric signal strength, connection status and conversation state. The orb consumes these events; it does not capture audio, request another microphone stream, handle credentials, or send customer data to GetLayers. Listening, processing and speaking map to the package states. Idle decoration does not imply an active conversation.

The aurora uses at most a 1000px render width and 25 frames per second. Mobile screens at 640px and below use a static CSS atmosphere. Hidden and offscreen aurora rendering pauses. The orb package manages its own page visibility and viewport lifecycle. Both have WebGL fallbacks. A persistent decorative-motion toggle and operating-system reduced-motion preference are supported. The dotted globe is decorative, without fabricated live activity.

Rebuild the orb assets with `npm run build:motion --prefix tools/vendor` after installing that directory's locked dependencies. The generated JS and CSS are committed because this existing static application does not run a bundler during deployment. The package license is in `assets/ORBLOOM-LICENSE`.

Verification: WebGL and no-WebGL browser rendering, desktop/tablet/mobile layout at 1440/1280/768/390/320px, persisted pause and reduced motion, ten procurement regression tests, and an isolated browser procurement journey using fixture authentication/data/voice provider. The fixture journey covers text, private attachment, request confirmation, dashboard, administrator quotation, client approval, voice transcript, mute and trial cutoff. It is not a live supplier or paid voice-provider test. Vercel deployment protection prevents this tool connection from independently accessing the signed-in Preview; deployment status is verified separately through Vercel metadata.

Only the `goprocures-ai` preview branch is updated. Existing backend routes, authentication, database policy and real voice transport are retained.
